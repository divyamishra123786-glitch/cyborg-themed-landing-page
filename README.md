# CYBORG-X — Techfest Web Development Task

A responsive cyberpunk/cyborg-themed landing page built with HTML, CSS and JavaScript.

## Features
- Responsive mobile/desktop layout
- Futuristic HUD-style hero section
- Animated orbit/core visual made with CSS
- Systems feature cards
- Terminal/protocol section
- Interactive Initialize System button
- Mobile navigation
- Smooth scrolling

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Submission
Upload this project to a GitHub repository and use the repository URL in the Techfest task submission. Record a short demo showing the homepage, scrolling sections, responsive view, and the Initialize System interaction. Upload the recording to Google Drive with viewer access.
